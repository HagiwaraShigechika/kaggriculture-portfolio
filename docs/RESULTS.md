# PPO実験の評価と学び

以下は2026年9月のv25実験で保存した記録です。今回の公開準備で再学習・再対戦した値ではありません。機械可読の集計と抽出元ハッシュは [`ppo_results.json`](ppo_results.json) に保存しています。

## 評価結果

独立した2学習をそれぞれ179更新・22,912試合、合計45,824試合で実施しました。開発評価で選んだtrain1の更新37を固定し、開発に未使用の64seed・両手番で最終評価しました。公開パネルの比較2,816試合と直接対戦256試合の合計3,072試合です。

| 比較 | 基準v24 | PPO候補v25 |
| --- | ---: | ---: |
| 公開6相手（各768試合） | 713勝55敗 | 693勝75敗 |
| active 11相手（各1,408試合） | 1,311勝97敗 | 1,289勝119敗 |
| v24への直接対戦（128試合） | — | 78勝50敗、60.94% |

対v24の得点率の95%区間は48.44〜72.66%。公開6相手に対する対応条件の得点率差は−2.604ポイント、95%区間は−5.469〜−0.260ポイントでした。対v24だけの勝ち越しを総合的な改善と解釈せず、**PPO候補は不採用**としました。現行 `main.py` は別のv33エージェントです。

bootstrapは環境seedを単位に、両手番・相手をまとめて再抽出しています。独立seedは64であり、3,072試合を独立な3,072標本とは扱いません。また、公開6ファイルには共通祖先があり、独立した最上位6系統と数えることはできません。オンライン順位やKaggleレートの改善も、この結果からは主張しません。

## 後退をどう調べたか

開発条件で、経路・投資・市場・農作業・労働の5群を一つずつ元に戻すアブレーションを実施しました。最良モデルと停止時モデル、6設定、各64試合の計768試合です。最終評価seedは使っていません。

| 開発条件での変更 | 最良モデルの得点率 | 停止時モデルの得点率 |
| --- | ---: | ---: |
| 全群を有効 | 96.875% | 37.5% |
| 農作業・飼育を基準に戻す | 96.875% | 65.625% |
| 売却・予約を基準に戻す | 75.0% | 59.375% |

最良時には市場判断が改善を支え、後半には農作業と市場判断が後退に関係していました。個々の判断の因果的な寄与率を確定した結果ではありませんが、単に学習時間を増やすより、探索・更新の設計を見直す必要があると判断できます。

## 実装・検証から得た知見

- 初期の最大確率選択が基準方策と一致しても、多数の確率的な選択によって学習中の行動が大きく変わる。初期方策を壊さない探索が課題です。
- 自己対戦は試合数で60%でも両席の経験を使うため、軌跡数では約75%となった。試合比率と更新に使われる経験比率を区別する必要があります。
- 判断頻度の低い経路と頻度の高い市場を同時に学習するため、群別の損失・KL・発動数を追う必要があります。
- 公式ローダー16試合で完走し、高速環境との行動・状態・資金の一致を確認した記録があります。これは実行品質の証拠であり、強さの改善とは別です。

学習を実装するだけでなく、未使用条件の評価、後退の検出、アブレーションによる原因の切り分けまでを研究成果として残しています。
